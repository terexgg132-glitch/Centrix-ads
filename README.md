# Centrix advertisement downloads

This branch provides the existing, verified Centrix advertisement as downloadable MP4 files. The videos have not been regenerated or re-encoded for this delivery.

## Download to your Mac

Open one of the files below in GitHub, then click **Download raw file** (the download-arrow button). If your browser opens the video, right-click it and choose **Save Video As…**. The MP4s can be played in QuickTime Player.

- [Social MP4 — 1080 × 1920](output/Centrix-Social-1080x1920.mp4), 3,143,273 bytes. Recommended for social media.
- [Master MP4 — 1080 × 1920](output/Centrix-Master-1080x1920.mp4), 4,672,639 bytes. Higher-quality export.

The advertisement is 26 seconds, 1080 × 1920, and 30 fps, with the original Egyptian Arabic voice and original score and sound design. Both MP4s are well below GitHub's 100 MiB individual-file limit.

The editable package and supporting source assets remain in the task workspace; this download branch contains only the two finished videos and these access instructions.
